# Совместимость

«Проверено» означает реальный импорт, поиск, чтение, экспорт и обновление в этой среде — а не
чтение кода.

## Confluence

| Confluence | Проверенная аутентификация | Статус |
|---|---|---|
| Server 8.5.22 — стенд, на котором писалась и проверялась разработка | логин и пароль (Basic) | проверено: 1734 статьи в 24 пространствах, полный и инкрементальный проход |
| REST-форма Server 8.x — мок в `engine/tests` | токен и логин/пароль, пейджинг, CQL, вложения, 401/403 | проверено |
| Server 7.x–9.x | Basic или токен | ожидается, не проверено |
| Data Center с Personal Access Token | Bearer | ожидается; Bearer покрыт моком, живой Data Center не проверялся |
| Confluence Cloud | — | не поддерживается: другие API и авторизация |
| HTML-экспорт из Server 8.x | — | проверено, включая старый экспорт windows-1251 |

## Аутентификация

- Basic (логин и пароль) работает на любом Server и Data Center.
- Токен работает только там, где сервер принимает `Authorization: Bearer`. Server без поддержки
  токенов отвечает как анонимный, и плагин сообщает `error.authRejected`, а не показывает пустой
  список пространств.
- Анонимный доступ отклоняется понятной ошибкой ещё до старта импорта.

|---|---|---|
| DSH Desktop | 0.2.2-rc.5 (раньше и rc.3) | `>=0.2.2-rc.1 <0.3.0` |
| Electron | 44.7 | входит в DSH |
| Node | 24.21.0 | `>=22.5.0` (`node:sqlite`) |
| Python | 3.12.14 (runtime DSH) | 3.12 проверен; более старые версии проверяются в CI |
| Операционная система | Windows 10/11 x64 | Windows проверен; macOS и Linux ожидаются, но не проверены |

## Как сообщить о проблеме

Приложите вывод `kb_status`, версию плагина, `kb.py --version`, версию Confluence со страницы
«О программе» сервера, режим аутентификации и шаги. Не вставляйте токены и пароли; скриншота
страницы настроек достаточно.
