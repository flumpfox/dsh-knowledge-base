# Решения

Короткие записи о выборе, который легко сломать случайно. Каждая говорит, что решено, почему и
чего стоит изменение.

### Ключи секретов — строго `<scope>/<id>`

Хранилище DSH принимает только два сегмента и не может загрузить файл, если ключ испорчен.
Плагин держит **одну запись на источник**, ключ `knowledge-base-tools/<id>`, а способ входа — в
payload. Ключи из трёх сегментов однажды уронили приложение на старте; смена формы означает
миграцию всех записей.

### Построитель инструментов грузится лениво

Связанный бандл разрешает импорты из рабочего каталога, а не из профиля, поэтому
`@deepseek-ai/dsh-tools` нет на его пути. Он импортируется сначала как обычный пакет, затем из
`app.asar` запущенного приложения. Без запасного пути плагин падал с `ERR_MODULE_NOT_FOUND`.

### Host объявляет `webServer` в inject

Маршруты регистрируются в `apply`, а на старте HTTP-носитель может быть ещё не готов.
`inject: ['tools', 'webServer']` заставляет активацию дождаться его; до этого маршрутов молча не
существовало.

### Запись из чужого origin отклоняется по правилу DSH

Запись без браузерных маркеров (`Origin`/`Referer`) разрешена — оболочка и локальные инструменты
их не шлют. Браузерная страница всегда шлёт свой origin, поэтому чужой origin и `Origin: null`
отклоняются с `error.crossOrigin`. Более строгое правило ломало все записи из самого приложения.

### У прогресса есть документированный контракт

Движок печатает `PROGRESS <done>/<total> <space>` в stderr при импорте и `PACK <done>/<total>` в
байтах при упаковке; Host разбирает ровно эти строки. Смена формата ломает и страницу, и тесты.

### Базовый URL фиксируется после импорта

Статьи хранят адрес, с которого пришли, поэтому правка URL при наличии контента заставила бы базу
лгать о происхождении. Поле становится только для чтения, Host отклоняет смену с
`error.baseUrlLocked`, а очистка базы обычного источника снимает фиксацию.

### Последний источник можно удалить

Пустой реестр — реальное состояние, а не повреждение: страница показывает пустое состояние, а
первый источник создаётся явно. Движок и инструменты переживают «нет источников» без подстановки
выдуманного умолчания.

### Экспорт пишет временный файл и переименовывает

Неудачная или отменённая упаковка не должна уничтожить предыдущий архив. Движок пишет
`<имя>.tmp` и заменяет целевой файл только при успехе; отмена удаляет временный файл.

### Подсчёт статей не включает `.md` из вложений

Страница может приложить markdown-файл; он едет в архиве, но не является статьёй. Подсчёт всех
`.md` давал в отчёте 1742 вместо 1734.

### Результаты инструментов дают абсолютные пути

Приложение разрешает относительную ссылку от рабочего каталога сессии, а база лежит в другом
месте, поэтому относительный путь ничего не открывает. Инструменты печатают абсолютные пути с
прямыми слэшами, а описания и скилл требуют цитировать их как есть.

### Встроенный браузер не получает креды плагина

Вкладка браузера — изолированная сессия Chromium со своей партицией, и она отвергает URL с
логином/паролем; Host не может подставить заголовки. Поддерживаемый путь — открыть первоисточник
в браузере по умолчанию.

### Движок находит базу по умолчанию через реестр

`--kb` выигрывает; без него движок читает `$KB_DIR` (или `~/.dsh/kb`) `knowledge-sources.json` и
берёт источник по умолчанию; без обоих — объясняет, что база не настроена, вместо угадывания пути.

### Формат архива читает старый маркер

Архивы пишутся как `knowledge-base.json` / `dsh-knowledge-base-base`, но
`confluence-kb.json` / `dsh-confluence-kb-base` ещё открывается, чтобы восстановить базу,
экспортированную до переименования. Убрать старый маркер позже — осознанное ломающее изменение.
