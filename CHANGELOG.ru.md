# История изменений

Публичные релизы начинаются здесь. Итерации 2.x были приватными сборками до публикации и в эту
историю не входят (их заметки остаются в приватном репозитории).

## 1.0.0 — 2026-11-19

Первый публичный релиз: плагин теперь называется **dsh-knowledge-base**.

### Добавлено

- Локальные базы знаний для агента из внешних источников. Сейчас поддерживается Confluence
  Server / Data Center — по REST API (Personal Access Token или логин и пароль) либо из
  zip-архива HTML-экспорта; в планах Jira, Obsidian и другие источники.
- Несколько источников, у каждого своя база, своё расписание и своя задача импорта. Один
  источник — основной; рабочая область может вместо него привязать упорядоченный набор.
- Четыре инструмента — `kb_search`, `kb_read`, `kb_review`, `kb_status` — с провенансом в
  каждом результате: дата изменения статьи, статус и флаги ревизии едут вместе с фактом.
- «Настройки → База знаний»: список источников, где первый источник создаётся с выбранными
  вами именем и id; проверка подключения, выбор пространств, расписание, живой прогресс с
  кнопкой «Остановить», последний запуск и наборы рабочих областей.
- Переносимые архивы баз: экспорт спрашивает папку и имя файла, показывает прогресс в байтах,
  отменяется, предлагает «Открыть папку» и переспрашивает перед заменой существующего файла.
  В архив попадает базовый URL, но никогда — учётные данные; импортируйте его на другой машине
  и продолжайте обновлять с того же сервера с новыми кредами.
- Базовый URL источника становится только для чтения после первого импорта; удаление файлов
  базы разблокирует его, удаление источника убирает и его файлы.
- Честная запись о каждом запуске на странице задач автоматизации: это отчёт, а не напоминание.
- Двуязычный интерфейс (ru/en); заголовки карточек инструментов следуют языку источника.
- Кроссплатформенные инструменты: `npm test`, `npm run pack`, `tools/check-secrets.mjs` и
  Python-запускатор скилла, работающий в Windows, macOS и Linux.

### Изменено

- Пакет — `@flumpfox/dsh-knowledge-base` (раньше имя было локальным); маршруты переехали на
  `/x-knowledge-base`, scope секретов — `knowledge-base-tools`, реестр — `knowledge-sources.json`,
  источники — в `~/.dsh/kb/<id>`, скилл — `knowledge-base`.
- Движок без `--kb` находит базу по умолчанию через реестр; `kb.py --version` печатает версию.
- Переносимые архивы пишутся как `knowledge-base.json` с `"format": "dsh-knowledge-base-base"`;
  архивы со старым маркером `confluence-kb.json` / `dsh-confluence-kb-base` по-прежнему открываются.

### Обновление

- С приватной сборки 2.x: автоматической миграции нет. См. `docs/UPGRADING.md` — переименовать
  каталог базы, создать источник заново, ввести учётные данные повторно.
